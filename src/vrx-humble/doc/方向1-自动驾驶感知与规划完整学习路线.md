> 适配背景：船舶与海洋工程/海洋智能硕士，本科机器人工程，目标是把 USV/UUV 项目能力迁移到自动驾驶、机器人、具身智能相关高薪岗位。

## 0. 方向定位：你到底要成为哪类候选人？

方向1不是“泛泛地学自动驾驶”，而是围绕以下 4 类岗位构建竞争力：

| 岗位方向 | 核心工作 | 对你最有利的切入点 | 推荐程度 |
|---|---|---|---|
| 自动驾驶感知算法 | 2D/3D检测、BEV、多传感器融合、跟踪、分割 | 海上目标检测、相机/雷达/LiDAR融合、低质环境鲁棒感知 | ★★★★★ |
| 自动驾驶规划算法 | 全局/局部路径规划、行为决策、轨迹优化、MPC | USV路径规划、动态避障、MPC控制基础 | ★★★★★ |
| SLAM/定位算法 | LiDAR/视觉/IMU/GNSS融合定位建图 | USV/UUV导航定位、LiDAR-inertial、组合导航 | ★★★★☆ |
| 机器人系统算法工程 | ROS2系统集成、仿真、部署、传感器链路 | 无人船系统闭环：感知→定位→规划→控制 | ★★★★☆ |

**主线建议：规划 + 感知双主线，SLAM作为系统能力补强。**

- 如果导师课题偏“自主航行/避障/编队”：主攻 **规划算法岗**，感知做到能集成。
- 如果导师课题偏“识别/检测/环境理解”：主攻 **感知算法岗**，规划做到能闭环。
- 如果云洲智能给你真实船/传感器数据：优先做 **系统闭环项目**，不要只做离线模型。

## 1. 你需要学习的完整知识地图

### 1.1 底层基础：必须补齐，否则后面会卡住

| 模块 | 必学内容 | 到什么程度算过关 | 典型产出 |
|---|---|---|---|
| C++17/20工程 | STL、智能指针、RAII、多线程、模板基础、CMake、gdb、性能分析 | 能写 ROS2 节点、能读 Autoware/Nav2 局部源码 | C++算法库 + ROS2节点 |
| Python工程 | NumPy、OpenCV、PyTorch、脚本化数据处理、可视化、argparse/yaml配置 | 能独立做数据清洗、训练脚本、评估脚本 | 数据处理工具链 |
| Linux/Git/Docker | Ubuntu、Shell、Git分支、Dockerfile、nvidia-container-toolkit | 能复现实验环境，能把项目交给别人跑起来 | 一键启动脚本/README |
| 数学 | 线代、概率、最优化、数值方法、李群李代数基础 | 能看懂 Kalman、MPC、图优化、坐标变换 | 推导笔记 + 小实现 |
| 控制理论 | PID、LQR、MPC、状态空间、离散化、约束优化 | 能实现路径跟踪控制器，并解释稳定性/约束含义 | USV/车辆MPC控制Demo |

### 1.2 机器人/自动驾驶通用栈

| 模块 | 必学内容 | 面试常问点 |
|---|---|---|
| ROS2 | node/topic/service/action/parameter/launch、tf2、QoS、Lifecycle、rosbag2 | ROS2 与 ROS1 区别、QoS策略、tf树、消息同步 |
| 传感器 | Camera、LiDAR、Radar、IMU、GNSS、编码器/速度计 | 各传感器优缺点、频率、噪声、标定、同步 |
| 坐标系 | ENU/NED、base_link、map、odom、camera、lidar、IMU坐标 | 外参/内参、旋转矩阵/四元数/欧拉角、坐标链 |
| 仿真 | Gazebo/Ignition、CARLA、Autoware demo、rosbag回放 | 仿真到真实的差异，如何构造测试场景 |
| 系统闭环 | 感知→定位→预测→规划→控制→可视化 | 延迟、频率、接口、故障降级、日志定位 |

### 1.3 感知算法栈

| 层级 | 内容 | 必学程度 |
|---|---|---|
| 传统视觉 | OpenCV、相机模型、畸变矫正、PnP、光流、特征匹配 | 必须掌握基础 |
| 2D检测 | YOLO系列、Faster R-CNN、NMS、IoU、mAP、数据增强 | 必须能训练和部署 |
| 图像分割 | semantic/instance segmentation、Mask2Former、SAM类模型概念 | 了解+能调用 |
| 点云处理 | PCL/Open3D、体素化、滤波、聚类、ICP/NDT、点云投影 | 必须掌握 |
| 3D检测 | PointPillars、SECOND、CenterPoint、PV-RCNN、BEV检测 | 必须至少深入一个 |
| BEV感知 | BEVFormer、BEVDet/BEVDepth、Occupancy、Transformer | 前沿加分项 |
| 跟踪 | Kalman Filter、EKF/UKF、SORT/DeepSORT、ByteTrack、AB3DMOT | 必须能实现基础版 |
| 多传感器融合 | camera-lidar投影、radar-camera、early/late/feature fusion | 自动驾驶核心能力 |
| 部署 | ONNX、TensorRT、FP16/INT8、Jetson/Orin、吞吐/延迟分析 | 工程加分项 |

### 1.4 定位/SLAM算法栈

| 模块 | 内容 | 学习目标 |
|---|---|---|
| 视觉SLAM | 特征法、直接法、VO、PnP、BA、回环检测 | 跑通 ORB-SLAM3，理解 tracking/local mapping/loop closing |
| LiDAR SLAM | ICP/NDT、LOAM、LIO-SAM、FAST-LIO2、点云地图 | 优先掌握 LiDAR-inertial，因为更接近自动驾驶工业需求 |
| IMU预积分 | IMU噪声、bias、预积分、紧耦合/松耦合 | 能解释 VIO/LIO 为什么需要 IMU |
| 组合导航 | GNSS+IMU+里程计/LiDAR融合、EKF、因子图 | USV场景特别重要 |
| 图优化 | Ceres、g2o、GTSAM、因子图、位姿图优化 | 能写一个小型pose graph优化Demo |
| 地图 | 栅格地图、点云地图、HD Map概念、语义地图 | 能支撑规划项目 |

### 1.5 规划/决策/控制算法栈

| 模块 | 内容 | 学习目标 |
|---|---|---|
| 全局规划 | Dijkstra、A*、JPS、D* Lite、Hybrid A* | A*必须手写；Hybrid A*是自动驾驶常见考点 |
| 采样规划 | RRT、RRT*、Informed RRT*、PRM、OMPL | 能解释概率完备/渐近最优，并用OMPL跑例子 |
| 局部规划 | DWA、TEB、人工势场、动态窗口 | 能做动态避障，并知道局限性 |
| 轨迹生成 | Frenet坐标、多项式轨迹、Bezier/B样条、minimum jerk/snap | 自动驾驶规划岗高频 |
| 优化规划 | QP/NLP、MPC、约束、代价函数、碰撞约束 | 结合你的控制基础重点突破 |
| 行为决策 | FSM、行为树BT、规则决策、简单博弈/预测 | Nav2和工业系统常用 |
| 路径跟踪控制 | Pure Pursuit、Stanley、PID、LQR、MPC | 做出“规划+控制”闭环 |
| 评价指标 | 碰撞率、到达率、舒适性、曲率、横纵向误差、计算耗时 | 项目报告/论文必须有 |

## 2. 具体路线：按时间推进

### 阶段A：研零到开学前（0~3个月）——打基础 + 做第一个可展示项目

**目标：** C++/Python/PyTorch/ROS2入门，做出“能跑、能展示、能写进简历”的小项目。

#### 第1~2周：开发环境与工程基础

任务：
- 安装 Ubuntu 24.04 + ROS2 Jazzy LTS（若实验室统一旧环境，可用 Ubuntu 22.04 + ROS2 Humble；不要把 Rolling 作为主线环境）。
- 熟悉 Git、CMake、Docker、VSCode/CLion、gdb。
- C++写 10 个小工具：读取CSV、KDTree最近邻、A*栅格搜索、线程安全队列、简单发布订阅Demo。

验收：
- GitHub 建一个 `autonomous-driving-notes` 仓库。
- 每个模块有 README、运行命令、结果截图。

#### 第3~6周：深度学习与2D检测入门

任务：
- PyTorch完整训练流程：Dataset/DataLoader、model、loss、optimizer、scheduler、eval、checkpoint。
- 学 CNN、ResNet、YOLO、NMS、IoU、mAP。
- 用 Ultralytics YOLO 训练一个海面/道路目标检测小模型。

建议数据：
- 入门：COCO子集、VOC、KITTI 2D。
- 贴近海洋：Singapore Maritime Dataset、SeaShips、MODD/海面障碍物数据（可根据可获得性选择）。

验收项目 P1：
```text
项目名：Maritime-YOLO-Detection
必须包含：
1. 数据集整理脚本：原始标注 → YOLO格式
2. 训练脚本和配置
3. mAP、Precision、Recall、混淆矩阵
4. 10张可视化结果
5. README说明如何复现
加分：导出ONNX并做一次TensorRT/ONNXRuntime推理测速
```

#### 第7~10周：ROS2 + Nav2 + 仿真

任务：
- ROS2：topic/service/action/launch/parameter/tf2/rosbag2。
- Nav2：map_server、AMCL/slam_toolbox、planner、controller、behavior tree。
- Gazebo/Ignition 或 Webots 中搭一个简化USV/小车环境。

验收项目 P2：
```text
项目名：ROS2-USV-Navigation-Demo
必须包含：
1. 机器人/无人船模型
2. 地图或仿真场景
3. Nav2自主导航：给目标点 → 自动规划 → 避障到达
4. rviz2可视化
5. rosbag录制与回放
加分：接入P1检测节点，把检测结果作为障碍物或语义信息发布
```

#### 第11~12周：路径规划算法库

任务：
- 手写 A*、Dijkstra、RRT、RRT*、DWA。
- 学习 Hybrid A*、Frenet、多项式轨迹、MPC概念。
- 先用 Python 快速实现，再挑 A*/DWA/MPC 用 C++ 重写。

验收项目 P3：
```text
项目名：Planning-Algorithms-Lab
必须包含：
1. A*/Dijkstra/RRT/RRT*/DWA 可视化对比
2. 动态障碍物测试场景
3. 指标：路径长度、平滑度、耗时、成功率
4. C++版本至少实现 A* + DWA
加分：MPC路径跟踪控制器
```

### 阶段B：研一上（3~9个月）——确定主攻：感知 or 规划

**目标：** 结合导师课题，完成一个“海洋无人系统 + 自动驾驶通用技术”的中型项目。

#### 路线B1：如果你主攻感知

学习顺序：
1. OpenCV + 相机模型 + 标定。
2. 点云基础：PCL/Open3D、体素滤波、RANSAC、聚类、ICP/NDT。
3. 3D检测：PointPillars → SECOND → CenterPoint。
4. 多传感器融合：相机-LiDAR投影、时间同步、外参标定、late fusion。
5. 跟踪：Kalman + Hungarian → SORT/DeepSORT → AB3DMOT。

验收项目 P4-G：
```text
项目名：USV-3D-Perception-and-Tracking
核心目标：在KITTI/nuScenes或海洋数据上完成3D检测+跟踪
必须包含：
1. 点云预处理和可视化
2. 至少训练/复现一个3D检测模型：PointPillars或CenterPoint
3. 2D/3D检测指标：mAP、NDS或KITTI AP
4. 跟踪指标：MOTA、ID Switch 或简化统计
5. 场景迁移分析：道路场景 → 海上场景有什么差异
加分：相机-LiDAR融合检测，或在Jetson/Orin上做部署测速
```

#### 路线B2：如果你主攻规划

学习顺序：
1. Nav2 planner/controller plugin 机制。
2. Hybrid A*、State Lattice、Frenet规划。
3. DWA/TEB/MPC局部规划。
4. 行为树/有限状态机：靠泊、避障、跟随、巡航。
5. 动态障碍物预测：匀速模型、Kalman、简单交互规则。

验收项目 P4-P：
```text
项目名：USV-Autonomous-Planning-System
核心目标：做一个可解释、可评估、可迁移的规划系统
必须包含：
1. 全局规划：A*/Hybrid A*
2. 局部规划：DWA/TEB/MPC 至少一个
3. 动态避障：移动障碍物轨迹预测 + 重规划
4. 行为决策：FSM或Behavior Tree
5. 路径跟踪：Pure Pursuit/Stanley/MPC
6. 指标：碰撞率、到达率、路径长度、耗时、跟踪误差
加分：封装成ROS2 Nav2插件
```

## 7. 最小可行路线（如果时间不够，就按这个做）

如果你只能聚焦一条线，按以下顺序：

1. **C++/Python/PyTorch基础**：2个月内补齐。
2. **YOLO目标检测项目**：1个月做完，形成第一个GitHub项目。
3. **ROS2/Nav2导航Demo**：1个月做完，形成系统项目。
4. **路径规划/MPC项目**：2个月做深，结合你的控制优势。
5. **3D检测或SLAM二选一**：根据导师数据和课题选择。
6. **研二前投实习**：不要等论文完全发出。

最推荐组合：
```text
主攻：规划算法（A*/Hybrid A*/MPC/Nav2）
补强：2D/3D感知（YOLO + PointPillars/CenterPoint）
系统：ROS2 + 仿真 + rosbag + 可视化
```

原因：你已有控制理论基础，规划/MPC更容易形成差异化；同时自动驾驶/机器人岗位需要你能接上感知输入，因此不能完全不学感知。

## 9. 不要踩的坑

1. **不要只调包不理解原理**：面试会问A*为什么最优、MPC代价函数怎么设计、NMS怎么做。
2. **不要项目没有指标**：没有mAP、FPS、碰撞率、到达率、耗时，就很难证明能力。
3. **不要只做海洋特化**：水动力、船体结构不是你的跳板重点；算法要可迁移。
4. **不要只做离线模型**：自动驾驶/机器人很看重系统闭环，至少要有ROS2/仿真/rosbag。
5. **不要过早追端到端大模型**：先把传统自动驾驶栈吃透，再涉猎VLM/端到端。
6. **不要忽视C++**：算法岗也常要求C++，规划/SLAM/系统岗尤其明显。
