## 二、方向推荐：按就业薪资排序

### 🔥 路径A：自动驾驶感知与规划（⭐⭐⭐⭐⭐ 强烈推荐）

**为什么选这个？**

- 你做的USV/UUV本质上就是**水面/水下无人车**，技术栈几乎一模一样
- 自动驾驶是目前**岗位最多、薪资最稳、跳槽最容易**的方向
- 海洋无人系统 → 自动驾驶的转换成本极低，简历上项目经历可以直接迁移
- 头部公司：华为、小鹏、蔚来、理想、百度Apollo、Momenta、地平线、大疆
- 薪资范围：硕士30-60万/年（2026年行情）

**技术重叠度分析：**

| 你在海洋项目中做的 | 自动驾驶公司需要的 | 重叠度 |
|---|---|---|
| USV环境感知（雷达/相机） | 自动驾驶感知模块 | ★★★★★ |
| 路径规划算法（A*/RRT*/DWA） | 自动驾驶规划模块 | ★★★★★ |
| SLAM/定位 | 自动驾驶定位模块 | ★★★★★ |
| 目标检测与跟踪 | 自动驾驶感知核心 | ★★★★★ |
| 编队协同控制 | 车路协同/V2X | ★★★★☆ |
| 嵌入式部署 | 车载计算平台部署 | ★★★★☆ |
| ROS开发 | ROS2/车载中间件 | ★★★★★ |
| 水动力学仿真 | 车辆动力学仿真 | ★★★☆☆ |

**硕士期间怎么把海洋项目做成自动驾驶的跳板：**

1. **不要只做海洋特化的东西**（比如水动力学、波浪补偿），这些跳不出去
2. **聚焦通用技术**：3D感知、点云处理、目标检测跟踪、路径规划、状态估计
3. **刻意使用自动驾驶技术栈**：用Apollo/Autoware框架思想做USV，简历上直接写"基于XXX框架的无人艇自主导航系统"
4. **发论文选题靠近感知/规划**，不要选纯控制或纯海洋的

---

### 🔥 路径B：具身智能/人形机器人（⭐⭐⭐⭐ 推荐）

**为什么选这个？**

- 2024-2026最火赛道，融资最多，人才最缺
- 你本科机器人工程+研究生做无人系统，完全对口
- 技术栈：强化学习 + 模仿学习 + 视觉语言模型 + 运动控制
- 头部公司：特斯拉Optimus、Figure、宇树科技、智元机器人、小鹏鹏行
- 薪资范围：硕士35-70万/年（抢人阶段，溢价高）

**但风险是：**
- 行业还在早期，2029年格局不确定
- 如果想走这条路，需要额外学强化学习/模仿学习，和导师课题关联度可能不高
- 适合你如果导师课题涉及决策/学习型控制

---

### 🔥 路径C：多模态大模型 + 机器人应用（⭐⭐⭐⭐ 推荐但难度最高）

**为什么选这个？**

- 薪资天花板最高，大模型方向硕士能拿到60万+
- 字节跳动正好是你导师的合作方，有天然实习通道
- 技术栈：VLM（视觉语言模型）+ 机器人任务规划 + 具身推理
- 头部公司：字节、百度、智谱、月之暗面、OpenAI/Anthropic（海外）
- 薪资范围：硕士40-80万/年

**但风险是：**
- 需要很强的编程和AI基础，学习曲线陡
- 和海洋课题的关联需要你自己创造（比如水下视觉大模型、无人船智能决策）

### ⭐ 最终推荐组合

```
主线：路径A（自动驾驶感知与规划）  —— 保底，就业面最广
```

- 研二暑假争取去**字节跳动或自动驾驶公司**实习
- 论文发在**ICRA/IROS/CVPR/AAAI**等通用顶会，不要只发海洋期刊

## 四、详细学习路线

### 阶段一：基础夯实（研零 ~ 研一上开学前）

> **目标**：把编程和数学基础补到位，能独立写项目

#### 4.1.1 C++强化（2-3周）

**你本科可能学过但不精，需要补到能写工程代码的程度**

学习内容：
- C++11/14/17新特性：智能指针、lambda、auto、range-based for、结构化绑定
- STL容器与算法：vector, map, unordered_map, set, priority_queue, sort, find_if
- 面向对象进阶：多态、虚函数表、模板编程基础
- 内存管理：堆栈区别、RAII、内存泄漏排查
- 多线程基础：std::thread, mutex, condition_variable, atomic

重点：
- **不需要学模板元编程、STL源码剖析这些屠龙技**
- **重点是能读懂ROS2源码级别的C++代码，能写多线程的数据处理pipeline**
- LeetCode刷50-100题（中等难度），重点刷数组、树、图、动态规划

资源：
- 《Effective Modern C++》Scott Meyers（选读前30条）
- Bilibili：侯捷C++系列
- LeetCode Hot 100

#### 4.1.2 Python进阶（1-2周）

**你肯定学过，但要补到能做数据处理和深度学习的水平**

学习内容：
- NumPy熟练使用（广播、索引、向量化计算）
- Pandas数据处理
- Matplotlib/Seaborn画图
- Python并发（多进程、异步基础）
- 类型注解、dataclass

重点：
- **NumPy必须滚瓜烂熟，后面所有深度学习和数据处理都靠它**
- 不需要学Web开发那些（Flask/Django/Django REST），和你没关系

#### 4.1.3 深度学习基础（4-6周）⭐⭐⭐ 核心中的核心

**这是你未来所有方向的共同基础，必须扎实**

学习顺序：

```
第1周：机器学习复习
  ├── 线性回归、逻辑回归、SVM
  ├── 决策树、随机森林、XGBoost
  └── 交叉验证、过拟合/欠拟合、偏差-方差权衡
  └── 资源：吴恩达 Machine Learning (Coursera) 或 李宏毅机器学习

第2-3周：神经网络基础
  ├── 前向传播、反向传播推导（手推一遍）
  ├── CNN：卷积、池化、感受野、经典架构(ResNet/VGG/Inception)
  ├── 损失函数：交叉熵、MSE、Focal Loss
  ├── 优化器：SGD、Adam、学习率调度
  └── 资源：李宏毅深度学习 + CS231n（看前8讲）

第4周：PyTorch实战
  ├── Tensor操作、自动求导
  ├── Dataset/DataLoader自定义
  ├── 模型定义、训练循环、验证循环
  ├── 预训练模型加载与微调
  ├── GPU训练、混合精度训练
  └── 资源：PyTorch官方教程 + 动手实现一个CIFAR-10分类

第5-6周：目标检测入门
  ├── Two-stage：Faster R-CNN原理（了解即可）
  ├── One-stage：YOLO系列原理（重点！）
  ├── Anchor-based vs Anchor-free
  ├── NMS、IoU计算
  ├── 数据增强策略
  ├── 实战：用YOLOv8训练一个自己的检测模型
  └── 资源：Ultralytics YOLOv8文档 + 动手做项目
```

**动手项目（必做）：**
```
项目1：用YOLOv8在公开数据集上训练目标检测
  - 数据集：COCO子集 或 海上目标数据集
  - 目标：理解完整的 训练→评估→推理 pipeline
  - 产出：GitHub仓库 + 效果可视化

项目2：实现一个简单的CNN图像分类
  - 从零用PyTorch写，不用框架的高级封装
  - 包含数据加载、训练、验证、保存/加载模型
  - 产出：代码 + 实验记录（学习率、epoch、loss曲线）
```

#### 4.1.4 Linux + Git（穿插在以上学习中，不单独花时间）

- Linux：基本命令、文件操作、SSH、tmux/screen、包管理(apt/pip/conda)
- Git：clone, add, commit, push, pull, branch, merge, rebase, .gitignore
- Docker基础：pull, run, build基本操作

#### 4.1.5 数学补强（穿插进行）

不需要系统重学，遇到不会的补即可：

| 数学工具 | 什么时候补 | 补到什么程度 |
|---------|-----------|-------------|
| 线性代数 | 学SLAM/3D感知时 | SVD分解、特征值、齐次坐标、旋转矩阵 |
| 概率统计 | 学贝叶斯滤波时 | 条件概率、贝叶斯公式、高斯分布、MLE/MAP |
| 最优化 | 学RL/规划时 | 梯度下降、拉格朗日乘子、凸优化基本概念 |
| 李群李代数 | 学SLAM时 | SE(3)/SO(3)的基本运算，不用深入证明 |

> **你已有基础**：考研专业课（自动控制原理+现代控制理论）覆盖了状态空间建模、传递函数、根轨迹、频域分析、能控能观性、状态反馈、最优控制(LQR)等，这些在SLAM（卡尔曼滤波）、规划（MPC）、控制（状态反馈）中都会直接用到，不需要重学。

#### 4.2.2 SLAM入门（4-6周）⭐⭐⭐

**SLAM是无人系统的核心技术，自动驾驶公司大量招SLAM工程师**

```
  ├── 图优化：g2o, GTSAM, Ceres Solver
```

#### 4.2.3 路径规划算法（3-4周）⭐⭐⭐

**规划算法是USV和自动驾驶的共同核心技术**

学习内容：

```
搜索-based 规划：
  ├── A*算法（必会，手写一遍）
  ├── Dijkstra（理解即可，A*的特例）
  ├── JPS（Jump Point Search）加速A*
  ├── D* Lite（动态环境重规划）
  └── Hybrid A*（非完整约束车辆，自动驾驶常用）

采样-based 规划：
  ├── RRT（快速随机树）
  ├── RRT*（渐近最优版本）
  ├── Informed RRT*（椭球采样加速）
  ├── PRM（概率路线图）
  └── 实战：在2D/3D环境中实现RRT*

优化-based 规划：
  ├── 贝塞尔曲线/B样条曲线平滑
  ├── 最小snap轨迹优化
  ├── 模型预测控制(MPC)基础  ← 你考研学过现控，状态空间建模/离散化/最优控制已懂，直接上手
  └── 混合A* + 曲线优化（Apollo风格）

行为规划：
  ├── 有限状态机(FSM)
  ├── 决策树
  └── 行为树(BT)：重点，Nav2原生支持
```

> **你的优势**：考研学过自动控制原理+现代控制理论，MPC的学习成本对你极低。状态空间建模、离散化、约束优化、LQR这些你已经有基础了，可以直接从MPC控制器跳到MPC规划器（自动驾驶中叫Lattice Planner / MPC-based Planner），这是规划岗的核心能力。

动手项目：
```
项目5：USV路径规划系统
  - 实现A*/RRT*/DWA在栅格地图上的对比
  - 加入动态障碍物避障
  - 用行为树组合多个规划策略
  - 在ROS2中集成到Nav2框架
  - 加分：实现MPC路径跟踪控制器（利用你的控制理论基础）
  - 产出：可视化对比 + 论文素材
```

## 八、心态建议

1. **不要等到"准备好了"再动手**：边学边做是最好的学习方式
2. **不要试图什么都学**：深度 > 广度，先把1-2个方向做到能写在简历上的水平
3. **不要小看海洋方向的项目经历**：面试官看的是你解决问题的能力，不是具体场景
4. **论文不是唯一产出**：GitHub上的高质量开源项目同样有说服力
5. **尽早开始实习**：研二暑假的实习几乎决定了秋招的走向
6. **保持和导师的良好关系**：导师的合作资源（字节/云洲）是你的核心杠杆
7. **985硕士 + 自动驾驶技术栈 + 大厂实习 = 毕业35-50万起**，这个组合是确定性很高的路径
